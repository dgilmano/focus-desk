# Focus Desk 0.5.0

- Start tracking opens a working session; Stop tracking ends the session and its running activity. Activity timers only start after Start tracking. Click the selected activity again to pause its timer.
- Untracked now counts only gaps within working sessions in daily, weekly and monthly balances. Time outside sessions, including overnight time, is excluded. Sleep and app exit stop tracking; recovery closes unfinished sessions at their last saved checkpoint.
- Day tracker now starts with a prominent, left-aligned Start tracking button, followed by the activity chooser and a compact timeline. Start and Stop buttons match activity-card widths; Stop uses the Leisure color.
- Click a timeline row for immediate selection; double-click to edit time, activity or linked task. Removed the Add interval button and corrected time-column alignment.
- Tracking sessions are included in backups. Existing tasks, Journal, drafts, tags and activity history are preserved during migration. Older backups remain importable; old activity history is shown without inventing working-session boundaries.

Personal preview for Apple Silicon, macOS 14 or later. This build is ad-hoc signed, not Apple Developer ID signed or notarized, and is not an App Store release. It is intended for the owner's locally installed copy. Updates verify signed metadata and archives and require saving data and creating a recovery backup before installation.
