# Focus Desk 0.3.0

- Day map now includes Weekly balance and Monthly balance alongside Daily balance. Switch between Day, Week, and Month to see recorded time by activity category.
- Browse previous weeks and months. Periods follow the selected date and system calendar; the current week or month counts only time that has elapsed.
- Recorded time and untracked gaps remain separate. Calendar boundaries, daylight-saving changes, and running activities are included in the totals.

Personal preview for Apple Silicon, macOS 14 or later. This build is ad-hoc signed, not Apple Developer ID signed or notarized, and is not an App Store release. It is intended for the owner's locally installed copy. Updates verify signed metadata and archives and require saving data and creating a recovery backup before installation.
