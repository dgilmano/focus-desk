# Focus Desk 0.4.0

- Day map is now called Day tracker. Drag activity cards to arrange them in your preferred order.
- Choose from ten color swatches and an expanded, searchable icon library with recently used icons.
- Timeline blocks reflect recorded duration. Drag their top or bottom edges to adjust start and end times with a live preview.
- Click a time to edit it directly in the timeline: Enter saves and Escape cancels. Click an activity or linked task name to change its assignment.
- Removed the pencil icon from recorded intervals. Additional interval options remain available with a right-click.

Personal preview for Apple Silicon, macOS 14 or later. This build is ad-hoc signed, not Apple Developer ID signed or notarized, and is not an App Store release. It is intended for the owner's locally installed copy. Updates verify signed metadata and archives and require saving data and creating a recovery backup before installation.
