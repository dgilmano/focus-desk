# Focus Desk 0.7.1

- Right-click a project, task or subtask in **Task map** and choose **Delete…**.
- Deleting a project removes its open and completed tasks, subtasks and journals together. The confirmation shows the number of tasks. Deleting an individual task keeps its subtasks in the project.
- Use **Undo** to restore a deletion in one action, including the project's task hierarchy and journal entries. Day tracker keeps the recorded intervals.

Personal update for Apple Silicon Macs running macOS 14 or later.
