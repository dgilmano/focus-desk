# Focus Desk 0.5.1

- Daily, weekly and monthly balances now show activities from the most time spent to the least. The chart follows the same order. Activities with equal durations retain their existing order.

Personal preview for Apple Silicon, macOS 14 or later. This build is ad-hoc signed, not Apple Developer ID signed or notarized, and is not an App Store release. It is intended for the owner's locally installed copy. Updates verify signed metadata and archives and require saving data and creating a recovery backup before installation.
