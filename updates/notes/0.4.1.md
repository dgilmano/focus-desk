# Focus Desk 0.4.1

- Restored compact, uniform rows in Day tracker. Row height no longer depends on recorded duration, and dragging interval edges has been removed.
- Kept direct editing: click a time to edit it, or click an activity or linked task name to change its assignment. Enter saves and Escape cancels time edits.
- Additional interval options remain available with a right-click, without a pencil icon.

Personal preview for Apple Silicon, macOS 14 or later. This build is ad-hoc signed, not Apple Developer ID signed or notarized, and is not an App Store release. It is intended for the owner's locally installed copy. Updates verify signed metadata and archives and require saving data and creating a recovery backup before installation.
