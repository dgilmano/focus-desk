# Focus Desk 0.2.0

- Check for Updates from the Focus Desk menu or with Option-Command-U. Download, install and relaunch without replacing the app manually.
- A successful save and local recovery backup are required before installing an update.
- Update metadata and archives are verified with Ed25519 signatures. Background downloading and system profiling are disabled.

Personal preview for Apple Silicon, macOS 14 or later. This build is ad-hoc signed, not Apple Developer ID signed or notarized, and is not an App Store release. It is intended for the owner's locally installed copy, not general public distribution. Task data stays on your Mac; GitHub only hosts the application updates.
